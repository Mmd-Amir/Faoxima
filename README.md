## 🌟 درباره فاکسیما

**فاکسیما (Faoxima)** یک سیستم یکپارچه، پیشرفته و خودکار برای فروش و مدیریت اشتراک و نمایندگی سرویس‌های VPN و پروکسی است که بر بستر پیام‌رسان تلگرام طراحی شده است. این پروژه بر پایه‌ی سورس محبوب **میرزا** توسعه یافته و ضمن بازنویسی و بازطراحی بخش‌های اصلی، پایداری بالاتر، تجربه کاربری مدرن‌تر و امکانات گسترده‌تری را در اختیار مدیران و مشتریان قرار می‌دهد.

فاکسیما از سه بخش اصلی که بر روی یک پایگاه‌داده مشترک فعالیت می‌کنند تشکیل شده است:

1. **🤖 ربات تلگرام (Telegram Bot):** محیط اصلی برای تعامل کاربران، خرید خودکار پکیج‌ها، شارژ کیف‌پول، تمدید، دریافت لینک اشتراک/QR و پشتیبانی تیکتینگ.
2. **📱 مینی‌اپ تلگرام (Telegram Mini App / SPA):** تجربه‌ای روان و نوین شبیه به یک اپلیکیشن مستقل درون محیط تلگرام؛ برای بررسی مانده حجم، تاریخ انقضا، خرید سریع و مدیریت سرویس‌ها.
3. **💻 پنل وب ادمین (Web Dashboard):** رابط کاربری مدرن تحت وب برای  مشاهده آمار فروش، مدیریت انبار و پایش کاربران.

## ✨ امکانات و مزایای کلیدی

| بخش | ویژگی‌ها و امکانات |
| :--- | :--- |
| 🚀 **بهینه‌سازی و عملکرد** | بازطراحی هسته و بهینه‌سازی کوئری‌ها جهت افزایش چشمگیر سرعت پاسخ‌دهی در مقایسه با نسخه‌های پیشین |
| 📱 **مینی‌اپ تلگرام** | تجربه خرید و مشاهده وضعیت کانفیگ در قالب Single Page Application (SPA) درون تلگرام |
| 🎨 **رنگ‌بندی و طراحی شیشه‌ای** | امکان شخصی‌سازی رنگ دکمه‌ها در سمت کاربر و ادمین، همراه با دکمه‌های شیشه‌ای مدرن |
| 🌟 **ایموجی‌های پرمیوم تلگرام** | پشتیبانی از نمایش ایموجی‌های پرمیوم در منوها و پیام‌های ربات (در صورت پرمیوم بودن اکانت سازنده) |
| 📦 **انبارداری و فروش عمده** | مدیریت پیشرفته انبار، امکان فروش دستی عمده، اتصال پنل اضطراری و انبار شبکه ملی |
| 📊 **کارت گرافیکی استعلام حجم** | صدور کارت گرافیکی زیبا و چشم‌نواز هنگام مشاهده حجم باقی‌مانده و زمان اشتراک |
| 🎫 **سیستم تیکت و پشتیبانی** | سیستم تیکتینگ یکپارچه با امکان تعریف دپارتمان‌های مختلف پشتیبانی |
| 🎁 **کدهای تخفیف و هدیه** | تعریف و مدیریت کدهای تخفیف درصدی/مبلغی و کدهای شارژ هدیه برای کاربران |
| 🔄 **سوییچ و اتصال چندپنلی** | قابلیت اتصال هم‌زمان به چندین پنل و سرور با تحویل کاملاً خودکار اکانت |

## 🧩 پنل‌های پشتیبانی‌شده

فاکسیما از انواع پنل‌های محبوب پشتیبانی می‌کند:

| پنل | شناسه سیستمی | نحوه احراز هویت | وضعیت |
| :--- | :---: | :---: | :---: |
| **مرزبان (Marzban)** | `marzban` | Username / Password | ✅ پایدار (Latest) |
| **پاسارگارد (PasarGuard)** | `PasarGuard` | Static API Token | ✅ پایدار (Latest) |
| **ثنایی (3x-ui)** | `3x-ui` | User/Pass + Web API | ✅ پایدار (Latest) |
| **Remnawave** | `remnawave` | Static Token + Squad ID | 🆕 پشتیبانی کامل |
| **ربکا (Rebecca)** | `rebecca` | Static API Token | 🆕 پشتیبانی کامل |
| **گارد (GuardCore)** | `guard` | API Key | ✅ پشتیبانی کامل |
| **فروش دستی (Manual)** | `Manualsale` | مدیریت کدهای انبار | ✅ پیش‌فرض |

## ⚙️ پیش‌نیازها

| عنوان | پیش‌نیاز مورد نیاز |
| :--- | :--- |
| **محیط اجرا** | سرور لینوکس (Ubuntu 22.04 LTS به بالا) یا هاست اشتراکی (cPanel / aaPanel) |
| **نسخه PHP** | **PHP 8.2** یا **PHP 8.3** |
| **اکستنشن‌های PHP** | `gd`, `intl`, `zip`, `sodium`, `curl`, `pdo_mysql`, `mbstring` |
| **پایگاه‌داده** | MySQL 5.7+ یا MariaDB 10.4+ |
| **دامنه و SSL** | دامنهٔ فعال دارای گواهینامه معتبر SSL (پروتکل `https://` الزامی است) |
| **کرون‌جاب (Cron Job)** | **اجباری** (جهت تمدید خودکار، گزارش‌ها، بررسی انقضا و یادآوری‌ها) |
